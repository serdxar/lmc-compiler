Stage-by-Stage Breakdown
1. Lexer (Tokenization)

Convert raw text into tokens.

Key tasks:

Define token types: INSTRUCTION, NUMBER, LABEL, COMMA, COMMENT, etc.
Handle labels (words ending with :)
Recognize instructions: LDA, STA, ADD, SUB, BRA, BRZ, HLT, etc.
Strip comments and whitespace
Track line numbers for error reporting

Output: List of Token objects with type, value, line number

2. Parser (Syntax Analysis)

Turn tokens into an Abstract Syntax Tree (AST).

Key tasks:

Implement recursive descent or table-driven parsing
Build an AST node for each instruction
Validate basic syntax (e.g., LDA expects a label/number)
Collect all labels and their positions (symbol table)

Output: AST root node + symbol table with label→address mappings

Example AST node:

python
class Instruction:
    def __init__(self, opcode, operand=None, line=None):
        self.opcode = opcode
        self.operand = operand  # Label name or number
        self.line = line
3. Semantic Analysis (Validation)

Check that the program is logically valid.

Key tasks:

Verify all referenced labels exist
Catch undefined variables/labels
Check operand types match instruction expectations
Detect unreachable code (optional)
Build final address table (labels → actual memory addresses)

Output: Validated AST + resolved symbol table

4. Code Generator (Compilation)

Convert AST to LMC machine code.

Key tasks:

Assign memory addresses to instructions (start at 0)
Replace label references with actual addresses
Convert instructions to 3-digit opcodes:
LDA → 1, STA → 2, ADD → 3, SUB → 4, etc.
Format: [opcode][address] (e.g., 105 = LDA address 5)
Output as plain text, binary, or hex

Output: Machine code file (one instruction per line or in binary format)
